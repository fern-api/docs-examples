This example shows how [Fern](https://buildwithfern.com) generates interactive API Reference documentation from a GraphQL schema. It uses a sample Plant Store GraphQL API with queries, mutations, and subscriptions.

Navigate to the **API Reference** tab to see the generated documentation.

## What's included

  <File name="docs.yml" comment="Configures navigation, theme, and hosting" />
  <File name="fern.config.json" comment="Sets your organization name and CLI version" />
  <File name="generators.yml" comment="Points to the GraphQL schema file" />
  <File name="schema.graphql" comment="Sample Plant Store GraphQL schema" />
  <Folder name="docs" defaultOpen>
    <Folder name="pages" comment="Markdown content for your documentation" />
    <Folder name="assets" comment="Logos, favicon, and other assets" />
  </Folder>
