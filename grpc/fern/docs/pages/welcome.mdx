This example shows how [Fern](https://buildwithfern.com) generates interactive API Reference documentation from Protocol Buffer (`.proto`) files. It uses a sample Plant Store gRPC API with unary RPCs and server-streaming.

Navigate to the [API Reference](/api-reference) tab to see the generated documentation.
